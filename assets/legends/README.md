# Echoes of Legend legend art

Complete updated legend-art build for the 115-card roster in the current `ART-SPEC.md`.

- Shipping files: **64 x 88 lossless PNG**
- Source files: `assets/legend-src/` at **640 x 880 JPEG**
- Manifest: `MANIFEST.csv`
- Rebranded faction IDs are applied: `asgard`, `hemithea`, `pandemonium`, `devas`, `genesis`, and `kami`.
- Hercules was regenerated for Hemithea; Poseidon, Adam, and Miyamoto Musashi were generated as new cards.
- Kaguya was moved from Yamato to Kami by filename/path only, per request; her existing art was not regenerated.
- No Chapter II legends remain outstanding.
